## 🧠 What I Do

### 🎮 Porting Games
I take games that were never meant to run on a platform and **make them work anyway**. From Android APKs to web ports, from Unity to HTML — if it's a game, I can bring it to life anywhere.

### 🛠️ Building Hacking Tools
I craft **reconnaissance tools**, **payload generators**, and **cyber-security dashboards** — real ones that work, not just toys. DNS lookups, WHOIS queries, subdomain enumeration, and more.

### 🌐 Websites & HTML
I build **dark, neon, cyberpunk interfaces** that look like they came from the future. Every pixel is intentional. Every animation is smooth. Every layout is responsive.

### 📱 Full-Stack Apps
From offline AI assistants to game hubs and classroom clones — I build things that work, that scale, and that impress.
